# Итерация 2 холста «GrePrepApp — направления дизайна» — общая спецификация

Решения Даши 05.10.2026: из шести направлений остаются «Е · Шаги» и «Г · Родной Telegram»
(их улучшаем по исследованию), добавляем три новых (Ж, З, И); в каждом ряду те же шесть
экранов; рамку имён бренда убираем. Предыдущий раунд Даша назвала «перенагруженным,
непонятно сложным» — главный критерий этой итерации: полезно, но не выглядит нагруженным;
хороший путь человека.

Корень файлов: `scratchpad/canvas-v2/project/`. Каждый экран — отдельный `.dc.html`,
390×844, по формату `artifact-type/reference/format.md` (скелет ниже).

## 1. Правила из исследования — пол для всех пяти рядов

1. **Одно главное действие на экране, всегда в одном месте** — нижняя кнопка Telegram
   (MainButton). Подпись несёт состояние и счёт: «Продолжить · вопрос 4 из 10»,
   «Дальше · 5 из 10», «Начать · 10 вопросов · ~12 мин», «Следующее слово · 4 из 12».
   Второстепенное — SecondaryButton слева от главной (тот же размер) или тихая ссылка.
2. **Приложение выбирает, человек может поменять.** Главная — не панель, а «что делать
   сейчас»: одно главное действие, максимум 2–3 тихих входа. Никаких графиков, процентов,
   счётчиков на главной.
3. **Конечная сессия с видимым концом** — «4 из 10» сегментами/точками.
4. **Разбор сразу и коротко, глубже — по нажатию, не больше двух уровней:**
   уровень 1 — вердикт + верный ответ + одна фраза «почему»; уровень 2 (раскрывается) —
   почему соблазнил ваш вариант; переключатель RU/EN; ссылка на тему (теория 3 мин);
   «Сообщить об ошибке» — мелко.
5. **Ошибка — спокойно.** Без заливки красным и тревожных цветов на весь экран; верно/неверно
   различаются ещё и значком и светлотой, не только оттенком (лучше синий/оранжевый, чем
   красный/зелёный).
6. **Никакой вины и игры:** без серий, очков, лиг, значков, красных счётчиков (в первой
   версии мотивации нет вообще).
7. **На экранах задания — ничего лишнего:** без маскотов, иллюстраций, анимаций по краям.
8. **Чтение:** текст задания 17–18 px, интерлиньяж ~1.45; основной текст ≥16 px; подписи ≥13 px.
9. **Telegram:** шапку рисует Telegram (52 px: слева «Закрыть» на главной / «‹ Назад» на
   вложенных, справа круглая «⋯»; **название по центру не рисуем — имени ещё нет**).
   Внизу — панель с MainButton. **Никаких нижних панелей вкладок**: главная — это узел,
   с неё всё открывается. Нет поддельной строки состояния.
10. **Пробный экзамен — как настоящий GRE:** интерфейс на английском (решение Даши),
    таймер можно скрыть, Mark / Review / Calculator, Back / Next. Back/Next — это
    SecondaryButton (слева) и MainButton (справа) Telegram. Метафора направления здесь
    почти выключена: «как на экзамене, когда это экзамен».
11. Касание ≥44 px. Настоящие `<button>`, `<a href>`; `aria-label` у кнопок-значков;
    `lang="en"` на английском тексте. Значки — свой inline SVG с обводкой, без эмодзи.
    Контраст текста ≥4.5:1.

### Нижняя панель Telegram (одинаковая геометрия во всех рядах — её рисует клиент)

- Панель: `flex: none; padding: 8px 16px 24px;` фон = фон страницы направления
  (setBottomBarColor), без теней; можно 0.5–1 px линию сверху, если содержимое над ней.
- Кнопка: высота 50 px, `border-radius: 12px`, во всю ширину; шрифт **системный**
  (`-apple-system, BlinkMacSystemFont, 'SF Pro Text', system-ui, sans-serif`), 17 px, 600 —
  кнопку рисует Telegram, наш у неё только цвет и текст.
- Две кнопки: в ряд, `gap: 10px`, Secondary слева (обычно `flex: 0 0 auto` или 1fr/2fr),
  Main справа.

### Шапка Telegram (52 px)

Сетка `1fr auto 1fr`, слева текстовая кнопка 17 px («Закрыть» или шеврон + «Назад»),
справа круглая кнопка «⋯» 44×44 (видимый круг 30–32 px). Цвета — в стиле направления
(у Г — из темы). Без названия по центру.

### Вопрос и разбор («‹ Назад»; интерактивная рамка)
Состояние: человек ответил на 4-й вопрос неверно.
- Прогресс: 4 из 10; 1 верно, 2 неверно, 3 верно, 4 — текущий (неверно), 5–10 впереди.
- Тип: Text Completion. Текст (en): «Although the committee’s report was praised for its
  thoroughness, critics noted that its conclusions were oddly ______, hedging on nearly every
  recommendation it made.»
- Варианты: A equivocal (верный), B incisive, C exhaustive (ответ человека), D dogmatic,
  E lucid.
- Уровень 1 (виден сразу), RU: «Неверно. Верный ответ — A, equivocal.» + «Подсказка —
  „hedging on nearly every recommendation“: выводы уклончивы. Это и есть equivocal —
  двусмысленный, уклончивый.»
  EN: «Incorrect. The answer is A, equivocal.» + «The clue is “hedging on nearly every
  recommendation”: the conclusions avoided commitment. That is what equivocal means —
  deliberately ambiguous.»
- Уровень 2 (раскрывается кнопкой «Почему не exhaustive?» / «Why not exhaustive?»), RU:
  «exhaustive — „исчерпывающий“. Соблазняет, потому что рядом стоит thoroughness. Но
  although требует контраста с похвалой, а не её повтора.»
  EN: «exhaustive (“covering everything”) is tempting because thoroughness appears nearby.
  But although signals a contrast with the praise, not a repeat of it.»
- Тема: «Слова-сигналы контраста · теория 3 мин». «Сообщить об ошибке» — мелко.
- MainButton: «Дальше · 5 из 10».
- Интерактив (state в `Component`): `lang` ru/en (по умолчанию ru) и `more` true/false
  (по умолчанию false — уровень 2 свёрнут). Обе кнопки рабочие, `aria-pressed` /
  `aria-expanded`.

### Слово («‹ Назад»)
Состояние: человек верно ответил, теперь видит полную карточку.
- Сессия слов: 3 из 12.
- «Верно. Следующее повторение — через 4 дня.»
- equivocal · [ɪˈkwɪvək(ə)l] · adj. · кнопка «Послушать».
- 1) двусмысленный, уклончивый — ambiguous or evasive, open to more than one
  interpretation — «The minister’s equivocal answer satisfied no one.» — «Двусмысленный
  ответ министра никого не устроил.»
- 2) неопределённый, неоднозначный (о результатах) — uncertain, inconclusive — «The
  results of the trial were equivocal.» — «Результаты испытания оказались неоднозначными.»
- Синонимы: ambiguous, evasive, noncommittal. Антонимы: unequivocal, clear-cut, categorical.
- Этап памяти 2 из 4; «выучено» — после 4 верных ответов подряд с перерывами.
- MainButton: «Следующее слово · 4 из 12».

Было: всё из темы Telegram, системный шрифт, сгруппированные списки. Риск был —

- **Тёмная тема — переключателем на каждой рамке** (`data-props`:
  `{"dark":{"editor":"boolean","default":false}}`). Реализация — CSS-переменные с

  Светлая — как у iOS-клиента: bg `#FFFFFF`, secondary `#EFEFF4`, section `#FFFFFF`,

  4 из 10».

  A–E; после ответа: строка верного варианта с синей/фирменной галочкой, строка
  ответа человека с оранжевым крестиком; ниже секция «Разбор» (уровень 1), строка

### Ж · Цвет раздела — «цвет говорит, где ты» (новое, файлы `G1…G6`)
Тезис: у каждого раздела своё сплошное цветовое поле; по цвету всегда понятно, где ты и
что делаешь. Хром удалён: нет карточек, рамок, теней — только цветные поля, крупный шрифт

строчная типографика, выбор заливает плитку цветом), но без обрезанных заголовков и
панорам: читаемость важнее.
- Шрифт **Manrope** (200/400/600/700/800, кириллица). Крупные слова разделов — строчные,
  200–300, 56–72 px, `letter-spacing: -0.03em`; интерфейс — 400/600.
- Поля: Verbal `#3E3BC2` (белый текст), Quant `#0B7A62` (белый), Слова `#C2462A`
  (белый, проверь контраст ≥4.5 для мелкого текста; при нехватке — темнее), Экзамен
  `#16181D` (белый), Повторить/слабые места — поле Quant или Verbal по теме.
  Фон листов `#FFFFFF`, вторичный текст `#545A66`, линии `#E4E6EA`.
  Верно — заливка полем раздела + галочка; ваш неверный — чёрная обводка 2 px + крестик
  + подпись «ваш ответ». Никакого красного.
- Главная: три горизонтальных цветных полосы во всю ширину, сложенные стопкой, высота
  по важности: верхняя (≈45%) — Verbal: строчное «verbal» крупно, «Text Completion ·
  4 из 10 · ~7 мин»; ниже Quant-полоса «повторить · проценты и доли · 8»; ниже полоса

- Вопрос: сверху полоса поля Verbal (~96 px) с «4 / 10» и тонкими сегментами белым;

  у невыбранных); разбор — на том же листе.

- Пробник: почти чёрное поле `#16181D` только в верхней полосе секции; ниже — белый
  экзаменационный лист.
- Конструктор: раздел выбирается большими цветными плитками (выбор = залитая плитка);
  готовые наборы — строки.
- Слабые места: три темы — три полосы цвета своего раздела, у каждой кнопка.

### З · Колода — «тренировка — это колода из десяти карточек» (новое, файлы `H1…H6`)
Тезис: сессия — физическая колода. Видно, сколько осталось (колода тоньше), конец — дно
колоды. Карточка — единственный предмет на экране; одна карточка = одна задача.
- Шрифт **Golos Text** (400/500/600/700, кириллица) для всего; английские слова и текст
  задания — тот же шрифт, крупнее.
- Фон — прохладный серо-голубой `#E7EBF0`; карточки белые, радиус 20–24, мягкая
  многослойная тень (`0 1px 2px rgba(20,30,50,.06), 0 8px 24px -8px rgba(20,30,50,.18)`);
  под верхней карточкой видны 2–3 края следующих карточек (смещение 6–8 px, чуть уже) —
  это и есть прогресс. Текст `#141A26`, вторичный `#56607A`.
  Акцент — чернильно-синий `#22337A` (MainButton, выбранное). Верно — синий `#1D5BD8` +
  галочка; ваш неверный — оранжевый `#C2410C` + крестик (синий/оранжевый вместо
  зелёного/красного).
- Главная: большая колода «Продолжить» (верхняя карточка: Verbal · Text Completion,
  «осталось 7 карточек · ~7 мин», мини-точки 4 из 10), ниже две маленькие колоды рядом:
  «Слова · 12» и «Ошибки: проценты и доли · 8». Тихие ссылки: «Собрать колоду»,
  «Пробный экзамен», «Слабые места». MainButton чернильная «Продолжить · вопрос 4 из 10».
- Вопрос: карточка с вопросом и вариантами; после ответа разбор появляется на
  «обороте» — нижней части той же карточки или второй карточкой, приложенной снизу;
  края колоды под ней: «ещё 6».
- Конструктор = «Собрать колоду»: готовые колоды (стопки-миниатюры) + своя: размер
  колоды 5/10/20 показан толщиной стопки; раздел, тип, режим — чипами.
- Слово: классическая флеш-карточка (лицо — слово; это состояние — оборот с
  значениями), под ней 4 точки этапа памяти.
- Слабые места: три колоды-темы с кнопками.
- Пробник: колоды нет — строгий лист; можно оставить только радиус и шрифт.

### И · Разговор — «разбор как переписка с репетитором» (новое, файлы `I1…I6`)
Тезис: тренировка — короткий диалог в языке, который человек знает наизусть, — языке
Telegram. Приложение спрашивает, человек отвечает нажатием, разбор приходит следующей
репликой; «Почему?», «RU/EN», «Теория» — кнопки быстрого ответа. В фокусе только последний
обмен репликами — ранние бледнеют (`opacity .45`), чтобы лента не копилась.
- Честность: реплики заранее написаны и проверены, это не живая модель — у «репетитора»
  нет человеческого лица и имени, только знак приложения (простая геометрическая
  метка), без слов «ИИ», «бот думает» и т. п.
- Шрифт **Geologica** (Google Fonts, кириллица; 400/500/600/700) — тёплый, чуть
  рукописный характер в больших размерах. Английский текст задания — тот же шрифт.
- Фон — светлый тёплый серо-зелёный `#EEF1EC` (не кремовый), реплики приложения —
  белые пузыри `#FFFFFF` (радиус 18, хвостик не обязателен), реплики человека —
  пузыри акцента `#DCEBDF`… или тёмные `#1F3A2C` с белым — выбери одно и держи.
  Акцент — глубокий зелёный `#1F6F4A`; кнопки быстрого ответа — пилюли 40–44 px с
  обводкой акцентом; главная кнопка — MainButton акцентом. Верно — акцент + галочка;
  неверно — тёплый оранжево-коричневый `#B4531F` + крестик.
- Главная: реплика «Вчера вы остановились на 4-м вопросе из 10 — Verbal, Text
  Completion. Продолжим? Осталось ~7 минут.» Под ней пилюли: «Сначала слова · 12»,
  «Повторить проценты · 8», «Другое…». MainButton «Продолжить · вопрос 4 из 10».
- Конструктор — короткий опрос по одному вопросу, у каждого уже выбрано умолчание
  (подсвечено): «Что тренируем?» Verbal ✓ / Quant / Эссе; «Сколько?» 5 / 10 ✓ / 20;
  «Разбор сразу или в конце?» Сразу ✓ / В конце, с таймером. Сверху пилюли готовых
  наборов («Как в прошлый раз», «Мои ошибки · 23»…). MainButton «Начать · 10 вопросов ·
  ~12 мин» доступна сразу — неотвеченное берётся по умолчанию.
- Вопрос: реплика-карточка с заданием (вопрос + варианты кнопками внутри), ответ
  человека — пузырь «C · exhaustive», ответ приложения — уровень 1; пилюли «Почему не
  exhaustive?», «EN», «Теория · 3 мин». Нажатие «Почему…» добавляет реплику уровня 2
  (интерактив). Ранние реплики бледнее.
- Слово: реплика «Что значит equivocal?» бледная (ранняя), ответ человека
  «двусмысленный, уклончивый», реплика «Верно. Повторим через 4 дня.» + карточка слова.
- Слабые места: реплика «За всё время 214 ответов. Больше всего ошибок в трёх темах:» +
  три строки с кнопками; пилюля «Ещё 2 темы».
- Пробник: переписки нет — строгий экзаменационный лист в шрифте и цветах направления.

## 4. Формат файла (каждый экран)

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<title>Ж · Цвет — Главная</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Manrope:wght@200;400;600;700;800&amp;display=swap">
<style>
body{margin:0}
a{color:#16181D}a:hover{color:#545A66}
button{font:inherit;cursor:pointer}
button,a{-webkit-tap-highlight-color:transparent;transition:transform 160ms cubic-bezier(0.23,1,0.32,1)}
button:active,a:active{transform:scale(0.98)}
:focus-visible{outline:3px solid #16181D;outline-offset:2px}
::selection{background:#DCDBF6;color:#16181D}
@media (prefers-reduced-motion: reduce){button,a{transition:none}button:active,a:active{transform:none}}
</style>
</helmet>
<div style="width: 390px; height: 844px; overflow: hidden; position: relative; box-sizing: border-box; font-family: 'Manrope', system-ui, sans-serif; color: #16181D; background: #FFFFFF; display: flex; flex-direction: column">
  <header>…шапка Telegram 52px…</header>
  <main style="flex: 1; min-height: 0; overflow: hidden; …">…</main>
  <div>…нижняя панель Telegram…</div>
</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":390,"height":844}}'>
class Component extends DCLogic {
renderVals() {
return {};
}
}
</script>
</body>
</html>
```

Правила, которые ломаются молча: строку `<script src="./support.js"></script>` не трогать;
закрывать каждый не-void элемент и брать атрибуты в кавычки; `{{hole}}` — только путь,
без выражений (всё считается в `renderVals()`); события — `onClick="{{fn}}"`; ветвление —
`<sc-if value="{{cond}}" hint-placeholder-val="{{ true }}">…</sc-if>`; никакого
`innerHTML`; `data-props` — в одинарных кавычках, `&amp;` для `&`. Раскладка — flex/grid
с `gap`. **Всё содержимое обязано помещаться в 844 px без обрезки** — сокращай
второстепенное, а не шрифт задания. Комментарии в разметке — по-русски, коротко и только
там, где неочевидно. В рамках — никаких пояснений дизайнера (они пойдут в стикеры).
