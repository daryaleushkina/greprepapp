# Направления дизайна — копия холста

Холст «GrePrepApp — направления дизайна» на claude.ai:
https://claude.ai/artifact/4pDFxjop5ddto1R6yjYm5H (открывается только у Даши).
Пока идёт выбор, источник правды — сам холст: Даша правит его там. Эта папка —
копия последней опубликованной версии, чтобы работа не жила только в облаке.

## Что внутри

| Путь | Что |
| --- | --- |
| `project/canvas.json` | раскладка холста: рамки, ряды, заметки |
| `project/Main.dc.html` | варианты имени бренда |
| `project/<буква><номер>-*.dc.html` | экраны: буква — направление (A — «Схема», B — «Поля», C — «Бланк», D — «Родной Telegram», E — «Словарь», F — «Шаги»), номер — экран (1 главная, 2 конструктор, 3 вопрос и разбор, 4 слово, 5 пробный экзамен, 6 слабые места; `D7` — главная в тёмной теме) |
| `BRIEF.md` | задание, по которому рисовались направления: содержимое экранов, обвязка Telegram, палитры и шрифты каждого направления |

Задания и слова на экранах — пример, свой, но публичный: в платный банк
контента он не идёт.

## Как продолжить

- Посмотреть и поправить руками — открыть ссылку выше.
- Поправить через Claude Code — сначала прочитать артефакт по ссылке
  (инструмент Artifact, `read`): на холсте могут быть правки Даши, которых
  здесь нет. Править файлы и публиковать в тот же адрес с корнем
  `design/directions` (пути `project/…`), не создавая новый артефакт. После
  правки — обновить эту копию.
- Проверить экраны без рендера:
  `python3 tools/design/lint-dc.py design/directions/project/*.dc.html`.

Формат `.dc.html` — раздел 2 в `BRIEF.md`.
