## 2. Каркас — первая задача кода

Веб (мини-апп и сайт, React + Vite), приложения на Swift (iPhone, iPad, Mac)
и Kotlin (Android), бэкенд на Go, Postgres, веб-админка — на своём
сервере за рубежом (OVH или Hetzner, `PRODUCT.md`, «Stack»; аккаунт заводит
Даша — до первой выкладки, а каркас и разработка идут локально). Ключ API
Anthropic — позже: конвейер контента и оценка эссе делаются на подменённом
API и переключаются на настоящий одной переменной. Платные аккаунты Apple
Developer и Google Play — перед публикацией в магазины (решения Даши
05.10.2026). Вместе с каркасом:

- **бэкенд на Go:** проверка initData, журнал запросов (одна строка на запрос,
  id запроса в ответе), ошибки клиента — в таблицу `client_errors`; миграции
  файлами и инструмент для них; локальный Postgres со своими портами (рядом
  на Маке стоят стеки LifeCommit и audioguide — `docs/HANDOFF.md`, «Грабли»);
- **тесты:** `go test -race`, интеграционные против локального Postgres,
  внешнее — через `httptest`; фронт — vitest с порогом покрытия, Playwright
  (iPhone/WebKit и Android/Chromium, обе темы), `checkScreen`, фикстура `me`,
  сид, `e2e/a11y.spec.ts` (axe, WCAG AA) по образцу LifeCommit;
  `docs/TESTING.md` по образцу audioguide — слои, что подменяется, что не
  покрыто;
- **гейт под Go и свой сервер:** переписать `scripts/hooks/pre-push` и
  `.github/workflows/deploy.yml` (сейчас pnpm и wrangler из LifeCommit) — фронт,
  `go vet`, `golangci-lint`, `go test -race`, e2e, сборка, деплой на сервер;
  запреты в `.claude/settings.json` — под новый способ деплоя; прогнать тесты
  хуков и дописать тест на `.claude/hooks/session-git.sh`;
- **агенты ревью** `gp-review-access` и `gp-review-errors` переписать под Go и
  Postgres (сейчас они про Worker, supabase-js и RLS);
- **сервер:** TLS, запуск сервиса, обновления, мониторинг места и доступности;
  ночная резервная копия Postgres с проверкой восстановлением на другой сервер
  (по образцу `tools/db/backup.sh` из audioguide, раннер — GitHub: репозиторий
  публичный, свой раннер к нему не подключать);
- **бот:** имя и тексты (`TEXTS` в `scripts/setup-bot.mjs`), вебхук на Go;
- переменная `DEPLOY_ENABLED=true` в GitHub — последним шагом, когда гейт
  зелёный.

## 3. Шкала баллов пробника

Решение Даши 05.10.2026: после пробного экзамена показываем верные и неверные
и примерный балл с пометкой «наша оценка, не официальная». Исследование, как
ETS считает баллы, и предложенный алгоритм нашей оценки (маршрут после первой
секции, таблица-якорь, диапазон, эссе, перцентили, сверка с баллами беты) —
`docs/SCORING.md`; решения Даши по нему приняты 06.10.2026 (три варианта
второй секции, диапазон крупно, скриншоты результата GRE с бета-пользователей,
оценка эссе ±1 с пометкой «бета»).

## 4. Контент

Порядок подготовки — `CLAUDE.md`, «Контент заданий». Объём на старте:

- 1000 слов (полная карточка, озвучка без сети);
- 200 заданий Verbal, 200 по математике (частично шаблонами — число
  подставляет приложение и само считает ключ), у каждого разметка: тема, тип,
  сложность; 2 пробных экзамена с тремя вариантами второй секции (лёгкий,
  средний, сложный) — 228 вопросов на оба пробника;
- 40–60 тем теории;
- темы эссе в формате GRE (свои; на пул ETS — ссылка) и эталонные эссе с
  оценками для сверки модели.

Конвейер: генерация Claude Opus 5.5 пакетами → независимое решение для
проверки ключа → веб-админка, где Даша принимает, правит или возвращает →
публикация; каждую ночь — выгрузка в приватный репозиторий. Эталоны для
промптов генерации и проверки ключа; каждый случай трижды подряд.

Проверка Даши — около 65–75 часов: главное, от чего зависит дата запуска.
Админку и конвейер делать раньше фич, чтобы проверка шла параллельно.

## 5. Фичи первой версии

Примерный порядок, каждая — с тестами по `CLAUDE.md`:

1. тренировки: конструктор, режимы «Практика» и «Проверка», разбор ошибки
   RU/EN, калькулятор, «Сообщить об ошибке»;
2. «что повторить»: итог тренировки, экран «Слабые места», «Повторить мои
   ошибки»;
3. словарь: интервальное повторение с проверкой;
4. теория по темам;
5. пробный экзамен один в один как настоящий, отдельные секции;
6. эссе с оценкой Claude Sonnet 5.5 — после сверки на эталонах (не тянет —
   Opus 5.5), с лимитом на человека;
7. оплата: бесплатная бета 4–6 недель → одна подписка, три кассы (Tribute,
   Apple, Google Play — `PRODUCT.md`, «Stack»), скидка бета-пользователям,
   7 дней пробного новым; вход через Telegram, Apple, Google.
