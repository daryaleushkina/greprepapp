# Бесплатные модели: генерация, оценка эссе, озвучка, речь

Исследование 10.10.2026 (по просьбе Даши: «бесплатные нейронки есть? изучить глубоко»). Условия — с
первоисточников на октябрь 2026; перед регистрацией сверить заново. Решений здесь нет — это материал для
них (`docs/ROADMAP.md`, §1, дорожка Б).

## Главные выводы

- **Генерация контента бесплатно — да.** Личных данных там нет. Бесплатный Gemini или локальная Gemma 4 /
  Qwen; ключ проверяет модель **другого семейства**, чем генератор (иначе «независимое решение» повторяет
  ошибки генератора). Минус бесплатного Gemini: Google может обучаться на нашем будущем платном контенте.
- **Оценка эссе и Speaking бесплатно — нет, честно не получится.** Бесплатный Gemini забирает тексты людей
  на обучение и чтение людьми, не разрешён для пользователей из ЕЭЗ и Великобритании и для продуктов, куда
  могут прийти дети (TOEFL сдают с 16 лет). Платный уровень без обучения на данных стоит копейки (ниже).
- **Озвучка бесплатно — да:** Kokoro-82M локально (Apache-2.0), для Listening с большим числом голосов —
  Google Chirp 3 HD в пределах бесплатного 1 млн символов в месяц.
- **Распознавание Speaking бесплатно — да:** faster-whisper на своём сервере; темп и паузы — по меткам
  времени. **Оценка произношения по звукам** бесплатно готовой нет: лучшее — Azure Pronunciation Assessment
  (платно, регистрация из России закрыта); своя (GOP на wav2vec2) — недели исследовательской работы.
- **Корпуса оценённых эссе для калибровки — все некоммерческие** (ELLIPSE, PERSUADE 2.0 — CC BY-NC-SA;
  TOEFL11 — только исследования). Нужен свой эталонный набор, как и записано в `PRODUCT.md`.

## Генерация и оценка (LLM)

| Вариант | Бесплатно | Качество | Обучение на данных | Гео и прочее |
| --- | --- | --- | --- | --- |
| Gemini API, бесплатный уровень (Flash, Flash-Lite) | около 1000 запросов в день у Flash-Lite (лимиты видны только в AI Studio) | хорошее | **да**, и чтение людьми | России нет в списке регионов; ЕЭЗ и Великобритания — только платно; только 18+ |
| Gemini, платный уровень | — | то же | нет | платёжный аккаунт |
| Groq | ~1000 запросов и 200 тыс. токенов в день | среднее–хорошее | не хранит | **Россия запрещена** |
| OpenRouter `:free` | 50 в день, после $10 кредитов — 1000 | зависит от модели | часть поставщиков обучается (отключается) | поставщики меняются |
| Mistral, бесплатный уровень | в консоли | среднее | да, по умолчанию | ЕС |
| Cloudflare Workers AI | 10 тыс. нейронов в день | Llama 3.3 70B, Qwen | нет | — |
| DeepSeek | бесплатного нет; flash $0,15–0,30 вход / $0,6–1,2 выход за 1M | хорошее | данные уходят в КНР | доступен из России |
| Локально: Gemma 4 (Apache-2.0), Qwen3.8-27B | бесплатно | черновики хорошие, уровень GRE и эссе — слабее облачных | данные не уходят | Мак 36 ГБ: 8–50 ток/с; **сервер без GPU не тянет** |

Cerebras — бесплатного уровня больше нет; GitHub Models — закрыт с 30.07.2026.

## Озвучка (TTS)

| Вариант | Бесплатно | Американский английский | Лицензия |
| --- | --- | --- | --- |
| **Kokoro-82M** | без ограничений, локально | 20 голосов; лучшие — af_heart, af_bella; мужские слабее | Apache-2.0 |
| Chatterbox | локально | хорошее, клонирование | MIT, но неслышимый водяной знак |
| Piper | локально | 20 голосов | **у каждого голоса своя**; lessac — только исследования; репозиторий в архиве |
| Coqui XTTS-v2 | — | отличное | CPML, некоммерческая — **нельзя** |
| F5-TTS | — | отличное | веса CC BY-NC — **нельзя** |
| edge-tts | — | отличное | неофициальный доступ — **нельзя** для коммерции |
| Google Cloud TTS (Chirp 3 HD) | 1 млн символов в месяц, дальше $30 за 1M | отличное | коммерция разрешена; Google Cloud не принимает новых клиентов из России |
| Gemini TTS, бесплатный уровень | лимиты в AI Studio | отличное, диалоги | выход наш; обучение на запросах (для своих текстов не страшно) |
| Azure F0 | 0,5 млн символов в месяц | отличное | коммерция разрешена; регистрация из России закрыта |

## Распознавание речи и произношение

| Вариант | Бесплатно | Качество | Лицензия |
| --- | --- | --- | --- |
| Whisper large-v3-turbo (faster-whisper / whisper.cpp) | локально | отличное, метки времени; звуки не оценивает | MIT |
| Parakeet-tdt-0.6b-v3 | локально | WER ~6,3 %, лучше Whisper | CC BY 4.0, коммерция разрешена |
| Vosk | локально | заметно хуже | Apache-2.0 |
| Azure Pronunciation Assessment | F0: 5 ч в месяц | лучшее готовое: звуки, беглость, просодия | коммерция; ~$1,3 за час (не подтверждено); регистрация из России закрыта |
| Speechace / ELSA API | — | хорошее | цены по запросу |
| Своя оценка (GOP: wav2vec2 + выравнивание, speechocean762) | бесплатно | для носителей русского не проверено | датасет Apache-2.0 |

Проверка «сказал ли слово» в режиме слов — встроенное распознавание устройства (решение Даши 10.10.2026),
бесплатно.

## Рекомендация

**На старте бесплатно:** озвучка — Kokoro на Маке разово (Listening — плюс Chirp 3 HD в бесплатном
лимите); Speaking — faster-whisper на сервере, темп и паузы по меткам времени, произношение — с пометкой
«примерно», без оценки звуков; черновики контента — бесплатный Gemini или локальные Gemma 4 / Qwen, ключ
проверяет модель другого семейства.

**Платить с первого настоящего пользователя** — за всё, где обрабатываются тексты и голос людей (эссе,
содержание Speaking): платный уровень без обучения на данных (Claude по `PRODUCT.md`, Gemini paid; DeepSeek —
только если Даша согласна, что данные уходят в КНР).

Оценка на 1000 активных в месяц (8 эссе и 15 минут Speaking на человека; цену Claude не сверяли):

| Статья | В месяц |
| --- | --- |
| Эссе, Gemini Flash-Lite / Flash | ~$31 / ~$54 |
| Эссе, DeepSeek flash | $10–19 |
| Содержание Speaking, Flash-Lite | ~$39 |
| Распознавание: Whisper у себя / Workers AI | $0 / ~$8 |
| Azure Pronunciation Assessment (250 ч) | ~$325 |
| Озвучка | $0 (разовая) |
| Генерация контента пакетами | $20–60 разово |

Итого ~$80–100 в месяц без Azure (~$0,10 на человека), ~$400 с Azure.

## Что потребует регистрации

- Отдельный проект и ключ Gemini в AI Studio; для платного уровня — платёжный аккаунт с нероссийской картой.
- Google Cloud с включённой оплатой — даже ради бесплатного миллиона символов Chirp.
- Azure — только если нужна оценка произношения по звукам.
- По желанию: Groq (Россия запрещена), OpenRouter, DeepSeek.
- Kokoro, Whisper, Parakeet, Gemma скачиваются без регистрации.

## Не подтверждено и не разобрано

Дневные лимиты бесплатного Gemini (только в AI Studio); цена Azure Pronunciation Assessment; лицензия
Qwen3.8-27B; скорость Whisper на процессоре сервера — замерить. 152-ФЗ (персональные данные граждан РФ за
рубежом) — не разбирали.
