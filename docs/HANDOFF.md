## Грабли

- **Облачная сессия подписывает коммиты «Claude <noreply@anthropic.com>»** из
  глобального конфига `/root/.gitconfig`. Хук `session-git.sh` ставит автора в
  локальный конфиг репозитория в начале сессии; на Маке со своим автором ничего
  не трогает. Если автор всё же Claude — `commit-msg` не пропустит коммит.
- **`npm i vitest@5` падает с «Cannot read properties of null (reading
  'edgesOut')»** — ошибка npm на пирах vitest; ставить с `--legacy-peer-deps` и
  явным `vite` (он у vitest 5 — пир).
- **Удалить ветку на GitHub из облачной сессии нельзя:** прокси обрывает
  `git push --delete`. Ветки удаляются на сайте.
- **В облаке нет `gh`.** Задачи — через GitHub MCP, зеркало — подать их JSON в
  `tools/dev/backlog.py` (как — в шапке файла).
- **Хук детектора `impeccable` в git не ездит** (`.claude/settings.local.json`):
  на Маке включить один раз — `/impeccable hooks on`.
- **Принудительный push в `main` из облака блокирует авто-режим Claude Code.**
  Переписать уже залитую историю — только с Мака или с явным разрешением.

## Грабли из LifeCommit и audioguide

Собраны 03.10.2026 из их `HANDOFF` — то, что касается платформы и
инструментов и укусит и здесь. Числа и версии сверять с конфигами каркаса.

### Машина и аккаунты

- **Облачные ресурсы (Cloudflare, Supabase) — спросить Дашу, в каком
  аккаунте**, до создания: аккаунтов несколько, и первый деплой LifeCommit
  однажды ушёл не туда. Поддомен workers.dev общий с другими проектами — имя
  воркера не должно совпасть.
- **Node 22.** На 20.x wrangler отказывается работать, а vitest падает на
  отсутствующем `styleText`. Версию держать одним файлом `.node-version` (его
  читает `setup-node` в CI). pnpm — прибить версией в `packageManager`; при
  странной ошибке pnpm сначала проверять это.
- **Bash на Маке — 3.2:** кириллица в именах переменных выполняется как
  команда, `UID` занят системой, команды `timeout` нет. Бегущий bash-скрипт не
  править — bash дочитывает файл по смещению и падает посреди слова.
- **Три локальных стека на одном Маке.** У audioguide и LifeCommit заняты Vite
  5173, wrangler 8787 и Supabase 543xx/554xx. GrePrepApp нужен свой диапазон
  портов Supabase и Vite с `--strictPort`, иначе Playwright с
  `reuseExistingServer` проверит чужое приложение, а второй стек молча пойдёт в
  чужую базу. Supabase поднимать урезанной, как LifeCommit:
  `supabase start -x realtime,storage-api,imgproxy,edge-runtime,logflare,vector,supavisor,mailpit,studio,postgres-meta`
  (Logflare с двумя стеками падает `Killed`).

### Telegram

- **Адрес мини-аппа, кнопка меню и тексты живут на самом боте**, не в деплое:
  выкладка зелёная, а кнопка ведёт на старую сборку. После переезда адресов —
  `getChatMenuButton`. «Главный мини-апп» (ссылки `t.me/<бот>?startapp=…`)
  меняется только в @BotFather. Всё остальное — одним скриптом
  (`scripts/setup-bot.mjs`; он сбрасывает накопившиеся обновления —
  `drop_pending_updates`).
- **Проверять версию клиента, а не наличие объекта:** в обычном браузере
  объекты Bot API есть, а вызовы уходят в никуда. «Внутри Telegram ли мы» — по
  `initData` и платформе. Геолокация в мини-аппе — через `LocationManager`, не
  `navigator.geolocation`.
- **iPhone (WKWebView):** `padding-bottom` у flex-контейнера прокрутки не
  учитывается — место под нижней панелью через `::after`, высота —
  `min(высота от Telegram, 100dvh)`. Горизонтальный свайп спорит с жестом
  Telegram «потянуть вниз» — выключать жест, только когда свайп уже
  горизонтальный. Сценарии — в Playwright-WebKit, симулятор — только для
  отрисовки.
- **`DEV_AUTH_BYPASS=1`** в `.dev.vars` заставляет Worker принимать поддельную
  initData — на этом держатся `pnpm dev`, e2e и CI; в прод не должен попасть.
- **Лимиты Bot API:** около 1 сообщения в секунду в чат и 30 в секунду всего —
  массовые ответы с паузами.
- **Клиент:** ответ 200 с оборванным телом — ошибка сети, а не пустой успех
  (пустой успех — только 204). Ответы приходят не по порядку — нужен общий
  счётчик изменений, чтобы старое перечитывание не затёрло свежее.
  `useState(начальное)` читается один раз — форма на другом объекте лечится
  `key`. В `pnpm dev` StrictMode грузит данные дважды — в проде этого нет.
- **Доступность из России:** мини-апп ходит только на свой Worker, не на
  `*.supabase.co`; шрифт — свой (`@fontsource-variable/…`), не Google Fonts.
  `localStorage` привязан к адресу и при смене домена сбросится.

### Cloudflare Workers

- **Один конфиг wrangler без окружений**, как в LifeCommit: в audioguide
  `wrangler deploy` без `--env` молча подменял боевой воркер. `workers_dev =
  true` не убирать. Пути, которые браузер открывает как страницу (возврат
  OAuth и т. п.), — в `assets.run_worker_first`, иначе SPA отдаст `index.html`.
- **«Выкладка прошла» ≠ «в бою новое»:** после деплоя сверять имя бандла и
  `/health` на боевом адресе; задача деплоя без секретов обязана падать
  красным. Секреты Worker'а живут в Cloudflare, GitHub нужны только
  `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
- **Кэш на границе сети не сбрасывается** (`caches.default.delete()` чистит
  один колокейшен) — рычаг только срок жизни и версия ключа ответа.
- **Фон:** хвост после ответа (`waitUntil`) обрывается — тяжёлое при входе не
  делать. Cron раз в 15 минут — задержка до 15 минут; кого обрабатывать,
  выбирать в SQL. В тестах cron не вызывать — он трогает всю базу. Бесплатная
  Supabase засыпает после 7 дней без запросов — будит тот же cron.
- **Задержка:** соединения с Postgres Worker не держит (PostgREST, новый клиент
  на запрос); запрос из Азии до Франкфурта — около 0,6 с, поэтому один экран —
  одно обращение к API, тяжёлое — одной SQL-функцией.
- **Квоты моделей общие на всех** (Workers AI — 10 000 нейронов в день на
  аккаунт, бесплатный Gemini — 429 и 503): дневной лимит на человека — в
  Postgres в той же транзакции, что запись; Rate Limiting Cloudflare ловит
  только всплески.

### Supabase

- **Миграция в бой — до вливания и совместимая со старым кодом:** вливание в
  `main` выкладывает воркер, и порядок «влила — потом накатила» дал 20 минут
  ошибок 502 при зелёном CI. CI миграции в бой не накатывает.
- **MCP `apply_migration` ставит версией время применения, а не номер файла**
  — после этого CLI отказывается работать («Remote migration versions not found
  in local migrations directory»). Накатила через MCP — сразу выровнять версию
  под имя файла; DDL через `execute_sql` не делать.
- **CLI к бою — через пул:** прямой хост `db.<ref>.supabase.co` только IPv6.
  `db push` может напечатать ошибку и всё равно «Finished» — проверять
  `migration list --linked`. Дамп — через CLI, системный `pg_dump` старше
  сервера.
- **Облако раздаёт права шире, чем локальный CLI:** `anon` и `authenticated`
  получают все права на новые таблицы, а `alter default privileges … revoke
  execute on functions` молча не срабатывает. Поэтому даже при «RLS без
  политик» — RLS на каждой новой таблице, `revoke execute` в той же миграции и
  сторож в CI.
- **Имена аргументов SQL-функции — часть интерфейса:** `rpc()` зовёт по именам,
  переименованный аргумент кладёт маршрут как удалённая функция. Типы —
  перегенерировать после таких миграций.
- **`set search_path`** у функций из триггеров и генерируемых колонок — иначе
  ломается восстановление дампа. `order by` в подзапросе не доживает до
  `jsonb_agg` — сортировать внутри агрегата.
- **Локальная база ≠ бой:** после `db reset` без статистики запрос может идти
  30 с (лечит `analyze`); бесплатный тариф даёт 60 соединений.

### Тесты и CI

- **Эталоны снимков сравниваются только на Маке**; на Linux (Actions, облако)
  — `ignoreSnapshots`, проверяются вёрстка, поведение и доступность. Проверка
  «ничего шире экрана» пропускает всё, у чего есть прокручиваемый предок.
- **e2e:** `retries: 1` вместе с `failOnFlakyTests`; язык и часовой пояс
  прибиты; Android-Chromium без `--use-fake-ui-for-media-stream` виснет на
  запросе доступа к микрофону.
- **Покрытие** считать по всему `src`, а не по импортированным файлам; порог —
  с запасом на ветки, зависящие от даты; `--passWithNoTests` даёт зелёный
  прогон без тестов; наборы в CI — каталогом, не списком.
- **GitHub Actions:** пока репозиторий публичный — бесплатны. Станет приватным
  (задача #3) — минуты платные, и облачный деплой надо проверить заранее.
  Свой раннер к публичному репозиторию не подключать никогда: чужой PR
  выполнится на машине.

### Claude Code

- **Секреты уже проходили через вывод инструментов** — поэтому Claude запрещено
  читать `.env*` и `.dev.vars*` (`.claude/settings.json`).
- **Текст пользователей, попадающий к агенту с доступом к коду, — путь для
  prompt injection**: сырой текст агенту не показывать.
